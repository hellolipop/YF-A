# AlphaDesk · A股 / 美股实时分析终端

一套可直接运行的**炒股分析系统**：参考虚拟货币实时分析终端（行情看板 + K线 + 指标 + 预警）的交互形态，
面向 **A股（沪深京）与美股** 两个市场，覆盖「看盘 → 选股 → 研判 → 回测 → 预警」的完整分析闭环。

- 后端：Python 3 标准库（零第三方依赖），多数据源自动降级 + 服务端缓存
- 前端：原生 JavaScript + Canvas 手绘图表（零第三方依赖），深色交易终端风格
- 启动：`./start.sh` 或 `python3 server.py --port 8848`，浏览器打开 `http://127.0.0.1:8848`

## 二、策略持续跟踪引擎（`engine.py`）

目标：**策略一直跑，观察 3 个月后的胜率与盈亏**。为避免"必须干等 3 个月"，引擎把观察期拆成两段：

```
   观察期起点（默认 3 个月前）                       今天                 目标 90 个交易日
   ├──────────────── 回溯段 backfill ────────────────┼──────── 实时段 live ────────►
   创建任务时一次性重放历史 → 立刻得到胜率/盈亏        引擎每 60 秒向前推进，持续累积记录
```

**推进状态机（每个任务独立）**

1. 判断最后一根K线是否"仍在形成中"：若其日期等于当日且当日尚未收盘（含午间休市），则不计入已收盘K线；
2. 对每根**新增的已收盘K线**：先以该根开盘价执行上一根产生的挂起信号 → 再做止损/止盈检查 → 再评估本根信号 → 记录权益快照；
3. 盘中若出现当日K线且存在挂起信号，则用**当日开盘价**立即成交，并可按盘中价触发止损止盈（标记为"实时"阶段）；
4. 每次推进后落盘 `data/strategy_runs.json`（8 秒节流，原子替换写入）。

**成交与统计口径**

- 信号在**收盘确认**，成交在**下一根K线开盘价**（规避未来函数）；A股按 100 股/手、美股按 1 股，含手续费与滑点；
- 交易分「回溯 backfill」与「实时 live」两类，界面上有独立标签，可只看实时段的真实表现；
- 指标：累计 / 年化收益、已实现与浮动盈亏、胜率、盈亏比、最大回撤、超额收益（对比买入持有）、观察期进度；
- 月度拆解：当月月末权益变动 + 当月已实现盈亏 + 当月交易数与胜率；
- 资金不足会**跳过买入信号并计数**（例如 10 万本金买不了 1 手贵州茅台），界面在信号日志与统计里明确标出。

**运行方式**

- 引擎随 `server.py` 启动而自动运行，**关闭浏览器后仍在跑**；服务停止期间不会推进，重启后会自动补齐缺失的K线（回溯+实时合并计算，不丢交易日）。
- 推进间隔可通过环境变量调整：`AD_STRATEGY_TICK=30 ./start.sh`（默认 60 秒）。
- 任务文件：`data/strategy_runs.json`（含持仓、逐笔交易、权益曲线、信号日志），删除该文件即清空所有任务。

## 三、数据来源与降级策略

所有行情请求由本地服务统一代理（规避浏览器跨域限制），并按以下顺序自动降级，任一数据源异常都不会让系统不可用：

| 数据 | 首选 | 备用 | 兜底 |
| --- | --- | --- | --- |
| A股 / 美股实时报价、五档、市值估值 | 腾讯行情 | 新浪财经（A股） | — |
| K线（日/周/月，A股+美股） | 腾讯行情 | 东方财富 | — |
| 分钟级 K线（A股） | 腾讯行情 | 东方财富 | — |
| 分钟级 K线（美股） | 东方财富 | 由分时数据聚合（标注为估算） | — |
| 分时（价格 + 均价 + 成交额） | 东方财富 | 腾讯行情（均价为估算） | — |
| 全市场快照（涨跌分布 / 榜单 / 选股） | 东方财富 | 新浪财经 | 本地磁盘快照 |
| 板块涨跌与资金 | 东方财富 | — | — |
| 资金流（主力净额） | 东方财富 | 新浪财经（仅主力净额） | — |
| 资讯、股票搜索 | 东方财富 | — | — |

- 服务端缓存：报价 5~6 秒、分时 12 秒、全市场快照 75 秒（A股）/120 秒（美股）、板块 40 秒，超时自动返回最近一次成功数据并标记 `stale`。
- 磁盘快照：`data/*.json` 保存最近一次成功抓取的全市场快照，上游全部不可用时可继续服务（界面会提示"本地缓存，数据可能延迟"）。
- 界面上会明确标注**当前数据的实际来源**（快照源、K线源、分时源）。

## 四、快速开始

```bash
# 方式一：一键启动（自动打开浏览器）
./start.sh            # 默认端口 8848
./start.sh 8899       # 指定端口

# 方式二：手动启动
python3 server.py --port 8848
# 浏览器访问 http://127.0.0.1:8848

# 调整策略跟踪引擎的推进频率（默认 60 秒）
AD_STRATEGY_TICK=30 python3 server.py --port 8848
```

环境要求：macOS / Linux / Windows，Python 3.8+（无需 pip 安装任何依赖）。

## 七、已知限制

1. **美股为活跃样本口径**：美股全市场约 1.4 万只，系统取"成交额前 N（默认 300~600）"作为活跃样本用于榜单与筛选，界面会显示实际样本数与口径说明；个股详情、K线、分时对任意美股标的均可查询。
2. **美股无公开五档盘口**：详情页仅展示最优买卖一档（美股行情源限制）。
3. **美股分钟级 K线**：公开接口未提供，系统用分时数据聚合生成，界面标注为"由分时数据聚合（估算）"；日/周/月 K线为真实数据。
4. **部分字段依赖特定数据源**：量比、涨速、主力净流入仅东方财富快照提供；当快照降级为新浪财经或本地缓存时，这些字段为空，界面会给出提示。
5. **公开接口存在频率限制**：系统已做缓存与降级，但当上游限流时，全市场类视图可能显示最近一次成功的数据（标记为本地缓存 / 延迟）。
6. **回测为简化模型**：单标的、全仓、信号次日开盘成交，未考虑涨跌停、停牌、流动性与融券做空，结果仅供策略逻辑验证。
7. **策略跟踪引擎的生命周期**：引擎随服务进程运行，服务停止期间不会推进（重启后自动补齐缺失K线）；如果电脑休眠或断网，实时段记录会出现空档，但历史回溯与后续推进仍然连续。
8. **策略跟踪的成交假设与回测一致**：不模拟盘中挂单排队、涨跌停无法成交、以及除息除权对持仓成本的影响；A股按 100 股/手取整，资金不足的买入信号会被跳过并计数。
9. **观察期长度受数据源限制**：分钟级周期（5/15/30/60 分钟）的历史K线公开接口只提供最近数百根，回溯窗口会短于所选月份；日/周/月K线可完整回溯 1 年。
